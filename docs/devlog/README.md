# Devlog nasıl çalışır
- `INDEX.md`: proje özeti + numaralı tablo. Her satırın "Detay" sütunu `entries/NNNN-*.md` dosyasına link verir.
- `entries/`: her adım için bir dosya. Eski kayıtlar değiştirilmez; düzeltme = yeni kayıt (`Supersedes`).
- Numaralar sıralı, 4 haneli, yeniden kullanılmaz.
- Format, ADR (Architecture Decision Records) ve changelog pratiklerinin birleşimidir: kısa indeks + ayrıntılı kayıt.
